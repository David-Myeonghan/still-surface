# 고요한 표면 · Still Surface

낯선 행성에 홀로 내려선다. 안개 낀 능선 너머로 희미하게 빛나는 기둥들이 서 있다.
가까이 다가가 **스캔**하면, 오래전 이곳에서 멈춘 한 문명의 신호가 하나씩 되살아난다.
일곱 개의 공명체를 모두 깨우면 — 하늘이 응답한다.

## 플레이 방법

| 입력 | 동작 |
| --- | --- |
| `W A S D` | 이동 |
| `Shift` | 달리기 |
| 마우스 | 3인칭 카메라 회전 (클릭하면 포인터 잠금) |
| `F` (홀드) | 근처 공명체 스캔 (2.5초) |

- 시점은 **3인칭** — 화면에 우주인이 보이고, 이동 방향으로 몸을 돌리며 달린다. 카메라는 뒤·위에서 따라간다.
- 화면 상단의 **나침반**이 가장 가까운 미스캔 공명체의 방향과 거리를 가리킨다.
- 공명체 근처에 서면 `F 스캔` 프롬프트가 뜬다. 홀드하는 동안 스캔 링이 채워진다.
- 스캔이 끝나면 해당 문명의 기록(로어)이 잠깐 떠오르고, 비콘이 따뜻한 색으로 바뀐다.
- 7/7을 채우면 피날레가 재생된다.

## 도파민 루프

이 게임의 핵심 재미는 단 하나의 감각에 집중한다 — **능선을 넘는 순간, 안개 너머에서
새 빛기둥이 떠오르는 그 장면.** 안개(FogExp2)가 드로우 거리를 제한해 먼 비콘을
가리고, 능선이 시야를 막는다. 플레이어가 걸어 올라 시야가 트이는 순간 발광 비콘이
Bloom과 함께 "팝인"한다. 발견 → 스캔 → 보상(로어 + 다음 비콘) → 다시 발견. 이 고리를
일곱 번 돌리면 엔딩.

## 기술 구조

- **Three.js + Vite + GLSL** — 빌드 기반 프로젝트.
- **하나의 지형 법칙:** `height(x,z,seed)` 순수 JS 함수가 유일한 진실. 플레이어 접지와
  지형 메시 정점을 같은 함수로 계산해 "발밑과 픽셀"이 정확히 일치한다(GPU/CPU 분기 없음).
- **순수 로직 ↔ 어댑터 분리:** `gen/`·`game/`은 Three 비의존 → `node:test`로 단위 검증.
  `core/`·`gfx/`·`ui/`·`audio/`는 렌더 어댑터 → Playbook 스모크(헤드리스 Chrome)로 검증.
- **절차 생성:** value-noise FBM 지형, seed 결정론(mulberry32). 같은 seed = 같은 세계.
- **후처리:** UnrealBloomPass가 emissive 비콘/빛기둥을 발광시켜 원거리 가시성을 만든다.
- **사운드:** WebAudio only — 앰비언트 드론, 상승하는 스캔 톤, 발견 차임, 피날레 스웰.

## 검증

- `npm test` — 순수 로직 16개 단위 테스트(rng·지형·유물 배치·스캔·나침반).
- `npm run smoke` — 실제 브라우저에서 부팅→7개 스캔→피날레 완료→0 에러 확인.
