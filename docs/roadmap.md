# 로드맵 · Still Surface

현재 버전은 **1행성 · 7공명체 · 도보 탐험 · 스캔/피날레**의 완결된 코어 루프다.
아래는 그 위에 얹을 수 있는 확장. 우선순위 순.

## Phase 1 — 탈것 (로버)

- 도보와 별개로 **로버 탑승/하차**. `E`로 근처 로버에 탑승, 다시 `E`로 하차.
- 로버는 빠르지만 급경사에서 미끄러진다 → 도보 정밀 접근과 역할 분담.
- 구조: `Player`와 같은 접지 로직(`height`) 재사용, 이동 모델만 교체(관성·바퀴 마찰).
  카메라는 3인칭 추적으로 전환.

## Phase 2 — 채집/제작

- 스캔 외에 **자원 채집**(광맥·크리스탈) 추가. 스캐너를 업그레이드해 더 먼 비콘 탐지.
- 최소 제작: 배터리(야간 탐험용 광원), 스캔 속도 부스트.

## Phase 3 — 다중 행성 / 낮밤

- seed만 바꾸면 새 행성이 생성됨(이미 결정론 확보). **행성 선택 허브** 추가.
- 낮/밤 사이클 — 밤에는 비콘 가시성↑, 시야↓ 로 긴장감 조절.

## Phase 4 — 모바일 앱 & 수익화

- **Capacitor로 래핑**해 iOS/Android 앱화. WebGL 캔버스 그대로 동작.
- 리워드 광고(AdMob): 스캐너 부스트·즉시 이동 같은 opt-in 보상. 웹 빌드는 목업,
  앱 빌드에서 `showRewardedAd()` 어댑터만 실제 SDK로 교체(게임 로직 무변경).
- 여러 토이 게임 공통 셸(광고·저장 어댑터) 공유.

## 유지보수 원칙

- 순수 로직(`gen/`·`game/`)은 항상 `node:test`로 커버. 3D 어댑터는 스모크로.
- "하나의 지형 법칙" 유지 — 접지와 렌더는 반드시 같은 `height()`를 쓴다.
