# 고요한 표면 (Still Surface) — 설계 문서

- **작성일**: 2026-08-02
- **한 줄**: 시드로 생성된 외계 행성 표면을 **1인칭으로 걸어다니며**, 흩뿌려진 **신비한 유물을 발견·스캔**해 행성의 비밀을 여는 3D 탐험 게임.
- **참고**: TheLongSilence (Three.js·GLSL·절차생성·내러티브)의 기술 수준. 단, 우리는 "우주 비행"이 아니라 **한 행성 표면 도보 탐험**으로 차별화.
- **목적**: 포트폴리오 대표작(3D/WebGL 실력) + 티스토리 iframe 임베드.
- **repo 슬러그**: `still-surface` (제목·이름은 변경 가능)

## 1. 핵심 원칙 — "도파민 루프" (설계의 중심축)

탐험 게임 도파민의 정체 = **"저 너머에 뭐가 있지?" → 넘어가니 처음 보는 광경/발견**. 이 한 문장을 모든 결정의 기준으로 삼는다.

**핵심 루프 (한 유물당):**
1. **먼 유혹**: 유물은 멀리서도 보이는 **빛기둥/발광 비콘**. 언덕이 시야를 가리므로, **능선을 넘는 순간 새 빛이 팟 하고 나타남**(가장 큰 도파민 지점). 안개·드로우거리를 이 "팝인"이 살도록 튜닝.
2. **접근**: 그 빛을 향해 걸어감. 나침반이 가장 가까운 미스캔 유물 방향을 가리켜 길잡이.
3. **발견/스캔**: 다가가 **F 홀드로 스캔** → 진행 링이 차오르고 음이 상승(긴장 고조).
4. **보상 폭발**: 스캔 완료 순간 → 유물이 개화(빛·파티클), **로어 카드**가 뜨고, **다음 비콘이 멀리서 새로 점화**되며, 하늘/대기 색이 미세하게 변함(세계가 반응). 진행도 3/7 상승.
5. **에스컬레이션**: 유물마다 보상이 조금씩 커지고, 7번째 스캔 시 **피날레(아페르투어)** — 하늘이 열리고 극적 연출 + 엔딩.

**도파민 강화 장치:**
- 발광 비콘 + Bloom(후처리)로 "멀리서도 눈에 띔".
- 능선 뒤 가림(occlusion)으로 "넘으면 발견".
- 스캔 = 즉시가 아닌 **홀드(2~3초)** → 기대 → 완료 쾌감.
- 완료 시 **다중 피드백**(시각+청각+세계 변화+진행도)로 보상 순간을 크게.

## 2. 스코프 (MVP) — 하나를 제대로

**포함:**
- **행성 1개** 표면(광활하게 느껴지되 실제론 유한한 대형 지형). 1인칭 도보.
- 시드 기반 **절차 지형**(FBM 노이즈 하이트필드) + **분위기**(대기 그라디언트 하늘·별·안개·발광).
- **유물 7개**: 시드로 지형 위 흩뿌림(서로·시작점에서 최소 거리 보장, 지형에 안착). 발광 비콘 + 스캔 상호작용 + 로어.
- **목표**: 7개 스캔 = 피날레/엔딩.
- **HUD**: 나침반(가장 가까운 미스캔 방향·거리), 진행도(n/7), 상호작용 프롬프트, 스캔 링.

**의도적 제외 (YAGNI → 로드맵):** 로버/탈것, 채굴·제작, 여러 행성, 낮/밤·날씨 사이클, 전투, 멀티플레이, 저장/이어하기(한 세션 완주형).

## 3. 스택

- **Three.js (WebGL2) + Vite 빌드 + 손수 짠 GLSL** (TheLongSilence 계열). 3D라 빌드 있음.
- **의존성 최소**: three(런타임), 개발용 vite·playwright. (앞 토이들의 "의존성 0"과 달리 3D는 예외.)
- **배포**: `vite build` → 정적 번들 → GitHub Pages(main/docs 또는 gh-pages) → 티스토리 iframe. iframe엔 `allow="pointer-lock; fullscreen"` + "새 탭 플레이" 폴백(포인터락 제약 대비).

## 4. 아키텍처 — 순수 로직 ↔ 3D 어댑터 분리 (테스트 가능성 유지)

**엔진은 Three를 모른다** 원칙을 3D에서도 지킨다: 게임 규칙(유물 배치·스캔 진행·나침반·피날레 판정)은 **Three 비의존 순수 모듈**로 두고 `node:test`, 렌더/입력/오디오는 어댑터.

| 계층 | 파일(예시) | 책임 |
|---|---|---|
| 순수 | `src/gen/terrain.js` | 시드 → 하이트필드 높이 함수 `height(x,z)` (FBM). Three 무관. |
| 순수 | `src/gen/artifacts.js` | 시드 → 유물 7개 위치(지형에 안착·최소거리). |
| 순수 | `src/game/state.js` | 스캔 진행·완료 판정·진행도·피날레 트리거. `scan(dt)`, `nearestUnscanned(pos)`. |
| 순수 | `src/game/compass.js` | 위치→가장 가까운 미스캔 방향·거리. |
| 어댑터 | `src/gfx/*` | 지형 메시·하늘/대기 셰이더·유물 발광·Bloom(PostFX). |
| 어댑터 | `src/core/Input.js` | 포인터락·WASD·F홀드. |
| 어댑터 | `src/core/Player.js` | 1인칭 카메라·이동·지형 위 걷기(높이 함수로 접지). |
| 어댑터 | `src/audio/Audio.js` | 앰비언트 드론·스캔 음·발견 스팅(WebAudio, 무에셋 지향). |
| 어댑터 | `src/ui/HUD.js` | 나침반·진행도·프롬프트·스캔 링·로어 카드·엔딩. |
| 조립 | `src/main.js` | 루프·조립·`window.__ss` 디버그 스냅샷(E2E용). |

- 지형 접지·충돌은 순수 `height(x,z)`를 렌더/플레이어가 공유 → 물리 엔진 불필요.
- 아트: 응집된 외계 팔레트 + Bloom + 대기 안개로 "싸게 강렬하게".

## 5. 검증

- **node:test**: terrain(같은 시드 같은 높이·결정론), artifacts(7개·최소거리·지형 안착), state(스캔 진행·완료·7개 시 피날레), compass(방향·거리). 순수 로직이라 브라우저 없이.
- **Playwright 스모크**(빌드/dev 서버): 로드 무에러, 이동으로 위치 변화, 유물 접근+스캔 홀드 → 진행도 증가, 7개 시 엔딩 상태. `window.__ss` 스냅샷으로 상태 검증.
- **실측 원칙**: "도파민 팝인"이 실제로 보이는지 스크린샷으로 확인(능선 너머 비콘 등장). 밸런스(안개거리·비콘 밝기)는 추측 대신 스크린샷/수치로.

## 6. 리스크

- **성능**: 대형 지형은 청크/LOD 또는 셰이더 기반 단일 메시 + 안개로 드로우거리 제한. 파티클·Bloom 과하지 않게.
- **포인터락 in iframe**: 티스토리 크로스오리진 iframe에서 제약 → `allow` 속성 + 새 탭 폴백.
- **길 잃음**: 나침반으로 항상 다음 목표 방향 제시 → 좌절 방지(도파민 유지).
- **스코프 폭주**: 로버·채굴 등은 철저히 제외, 7유물·1행성 완주형으로 고정.

## 7. 로드맵 (MVP 이후)

Phase 1 로버(탈것) · 낮/밤·날씨 · 유물 종류 다양화. Phase 2 여러 행성(포털) · 저장. Phase 3 사운드/연출 고도화. Phase 4 모바일(터치 조작) — TheLongSilence처럼 터치 스틱.
